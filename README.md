# MSU MPI CUDA Workshop

A 3D wave-equation solver developed for an MSU parallel-programming workshop. MPI divides
the domain between processes, while CUDA performs numerical updates on GPUs.

Решатель трёхмерного волнового уравнения, созданный для практикума МГУ по параллельному
программированию. MPI распределяет расчётную область между процессами, а CUDA выполняет
численные расчёты на GPU.

## Описание

При обменах MPI граничные данные копируются между памятью GPU и памятью хоста.

При включённом на этапе компиляции макросе `data_write` программа
создаёт снимки VTK. Независимо от него выводятся времена основных этапов,
поэтому репозиторий также служит примером реализации MPI + CUDA.

## Разработка и проверка изменений

**Основные точки изменения:**

- `src/mpi_cuda.cu` - разбиение вычислений MPI, GPU-ядра и обмен данными;
- `CMakeLists.txt` - сборка и зависимости MPI/CUDA.

**Поток вычислений:** `main()` раскладывает число MPI-процессов (степень
двойки) по трём координатам `num_blocks` и выделяет каждой задаче локальный
блок с одной граничной (halo) ячейкой с каждой стороны по каждой оси.
`init`, `first_step` и `solve` - CUDA-ядра для временных слоёв; два GPU-буфера чередуются по номеру слоя.
Перед следующим шагом граничные плоскости копируются GPU -> host,
обмениваются через `MPI_Isend`/`MPI_Irecv`, затем копируются host -> GPU.
`from_cord_to_rank()` циклически замыкает координаты соседей.

**Инварианты:** число процессов должно быть степенью двойки; размеры сетки
должны согласовываться с разбиением на блоки (код использует целочисленное
деление без обработки остатка). Правки CUDA-ядер, индексов и MPI-тегов
нельзя рассматривать независимо от размещения halo-слоёв и порядка обмена.
Граничные обмены используют шесть направлений и массив из 12 запросов MPI.

**Проверка изменений:** отдельно проверьте разбиение сетки, соседей по
границам, обмен halo, два временных слоя и корректность численного расчёта.
Проверка численной точности и обменов требует MPI/CUDA-стенда; в репозитории
нет отдельного набора автоматизированных тестов.

## Сборка

Нужны CMake, MPI, CUDA Toolkit и совместимый NVIDIA GPU.

```sh
cmake --preset release
cmake --build --preset release
```

Исполняемый файл:

```text
build/release/mpi-cuda-waves
```

## Запуск

Количество MPI-процессов должно быть степенью двойки. Первый необязательный аргумент задает размер сетки по трем пространственным направлениям.

```sh
mkdir -p plot
mpirun -np 4 ./build/release/mpi-cuda-waves 128
```

Программа печатает размер задачи, количество процессов и время выполнения
отдельных этапов. Запись VTK-файлов в `plot/` находится под `#ifdef data_write`
в `src/mpi_cuda.cu` и требует включения этого макроса при компиляции.
Обычный запуск без него не создаёт VTK-снимки.

## Реализация

Каждый MPI-процесс хранит свой трехмерный блок на GPU. CUDA kernels вычисляют очередной временной слой, а MPI обменивает граничные данные с соседними процессами.

Проект учебный и исследовательский: параметры схемы и распределения вычислений находятся в исходном коде и рассчитаны на эксперименты с параллельной реализацией.
